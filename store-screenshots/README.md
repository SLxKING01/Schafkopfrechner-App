# Store-Screenshots

- `apple-6.9/`: 1290 × 2796 px, für iPhone 6,9" in App Store Connect (Apple skaliert sie für kleinere iPhones).
- `google-phone/`: 1080 × 1920 px, für Smartphone-Screenshots in der Google Play Console.

Reihenfolge = Dateinummer. Inhalt ist ein Beispiel-Spielabend mit erfundenen Namen.

Neu erzeugen nach Design-Änderungen: Web-App starten (`CI=1 npx expo start --web --port 8099`), dann `node scripts/store-screenshots/run.cjs`.
