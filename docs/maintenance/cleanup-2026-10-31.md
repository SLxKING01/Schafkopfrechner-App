## Wiederherstellung

Eine entfernte Datei lässt sich aus dem Projektverzeichnis gezielt wiederherstellen:

```powershell
git restore --source=0ed95546e2aeb607a55b141579012a0dca755d19 -- src/components/game/AddPlayerModal.tsx
```

Für die alte Navigation gehören mehrere Dateien zusammen. Alle ausschließlich entfernten Dateien aus dem Manifest können gemeinsam zurückgeholt werden:

```powershell
$cleanupManifest = Get-Content -LiteralPath 'docs/maintenance/cleanup-2026-10-31.manifest.json' -Raw | ConvertFrom-Json
$restorePaths = @($cleanupManifest.files | Where-Object change -eq 'remove' | ForEach-Object { $_.path })
git restore --source=0ed95546e2aeb607a55b141579012a0dca755d19 -- @restorePaths
```

Zur Wiederverwendung einzelner Styles das Original aus dem Archiv in einen **separaten Ordner** entpacken und die benötigten Style-Blöcke anhand der Namen im Manifest übernehmen. Ein pauschales Zurücksetzen der vollständigen aktiven Screens würde auch spätere Änderungen an diesen Dateien überschreiben. Gleiches gilt für `.gitignore`.

Optional kann die ZIP-Prüfsumme kontrolliert werden:

```powershell
$cleanupManifest = Get-Content -LiteralPath 'docs/maintenance/cleanup-2026-10-31.manifest.json' -Raw | ConvertFrom-Json
Get-FileHash -LiteralPath $cleanupManifest.backupArchive -Algorithm SHA256
$cleanupManifest.backupArchiveSha256
```
